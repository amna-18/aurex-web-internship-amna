# Amna - Full-Stack Web Development Internship

## Week 1

### Task Description
Created a personal profile webpage using HTML5 as part of the AUREX Full-Stack Engineering Internship Week 1.

### Technologies Used
- HTML5
- Git
- GitHub

### How to Run Locally
1. Open the project folder.
2. Open `index.html` in a web browser.
3. The personal profile webpage will be displayed.

- Learned semantic HTML elements.
- Learned how to create navigation links.
- Learned how to create forms.
- Learned basic Git and GitHub concepts.

### Difficulties / Blockers
